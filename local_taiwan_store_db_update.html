台湾店舗データベース更新ツール

ローカル専用ツールです。店舗の追加行を読み込み、既存 JSON に追記した新しいファイルを作成します。GitHub には自動接続しません。

1. 現在のデータベースを読み込む

リポジトリーの dB/taiwan_store_db.json を選択してください。行は追加専用で、既存の ID と重複する行は無視します。

JSON ファイルを選択してください。

2. EmailJS から返された値の行を貼り付ける

1 行につき 1 件。例のような JSON 配列を複数行貼り付けられます。レコードの削除や上書きは行いません。

データベースと値の行を読み込んでください。

3. 更新した JSON を保存して GitHub に同期する

作成したファイルをリポジトリーの dB/taiwan_store_db.json に置き換え、通常の git commit / push で GitHub に公開します。これはローカルから GitHub への一方向更新です。
